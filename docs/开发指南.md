## 1. 项目技术架构

### 1.1 整体架构

本项目是一个基于Python的桌面应用程序，采用模块化设计：

```
┌─────────────────────────────────────────┐
│           桌面应用主程序                  │
│  ┌──────────────┐  ┌──────────────┐    │
│  │  系统托盘    │  │  Flask服务   │    │
│  │  (pystray)  │  │  (Web UI)    │    │
│  └──────────────┘  └──────────────┘    │
│           │                │            │
│           └────────┬───────┘            │
│                    │                    │
│            ┌────────▼────────┐          │
│            │   工具管理器     │          │
│            │  (ToolManager)  │          │
│            └────────┬────────┘          │
│                     │                   │
│    ┌────────────────┼────────────────┐ │
│    │                │                │ │
│ ┌──▼──┐      ┌──────▼──────┐  ┌─────▼──┐│
│ │爬虫 │      │  工具2      │  │ 工具N  ││
│ │工具 │      │  (未来)     │  │(未来)  ││
│ └─────┘      └─────────────┘  └────────┘│
└─────────────────────────────────────────┘
```

### 1.2 技术栈

- **后端框架**: Flask 2.3.0+
- **前端**: HTML + CSS + JavaScript（原生，无框架）
- **浏览器自动化**: Playwright 1.40.0+
- **系统托盘**: pystray 0.19.0+
- **图标处理**: Pillow 10.0.0+
- **打包工具**: PyInstaller 6.0.0+
- **操作系统**: Windows 10/11

### 1.3 核心模块说明

#### 1.3.1 主程序入口 (`src/main.py`)

**职责**:
- 应用生命周期管理（启动、运行、关闭）
- 系统托盘初始化和管理
- Flask服务启动（在独立线程中）
- 浏览器自动打开
- 信号处理和优雅关闭

**关键流程**:
```python
1. 初始化浏览器路径
2. 检查/添加开机自启动
3. 初始化浏览器池
4. 初始化工具管理器
5. 创建Flask应用
6. 启动系统托盘（如果启用）
7. 在独立线程中启动Flask服务
8. 自动打开浏览器（如果启用）
9. 主线程等待，直到收到关闭信号
```

#### 1.3.2 Flask应用 (`src/app.py`)

**职责**:
- 创建Flask应用实例
- 初始化浏览器池
- 初始化工具管理器
- 注册API和Web路由

**路径处理**:
- 开发环境：使用相对路径（`src/web/templates`, `src/static`）
- 打包环境：使用绝对路径（exe同目录下的`web/templates`, `static`）

#### 1.3.3 工具管理器 (`src/tools/manager.py`)

**设计模式**: 单例模式

**职责**:
- 工具注册和管理
- 工具生命周期管理（初始化、清理）
- 提供工具信息查询接口

**工具接口** (`src/tools/base.py`):
- `get_info()`: 获取工具信息
- `initialize()`: 初始化工具
- `cleanup()`: 清理工具资源
- `get_template_name()`: 获取HTML模板名称
- `get_api_prefix()`: 获取API前缀

#### 1.3.4 系统托盘 (`src/tray/tray_icon.py`)

**技术**: pystray库

**职责**:
- 创建和管理系统托盘图标
- 处理右键菜单事件
- 处理双击事件

**图标来源**:
1. 优先从文件加载：`src/static/images/icon.png` 或 `icon.ico`
2. 如果文件不存在，使用PIL动态生成默认图标

#### 1.3.5 开机自启动 (`src/utils/startup.py`)

**技术**: Windows注册表操作

**注册表位置**:
```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
键名: JNSpider
值: "C:\path\to\main.exe"
```

**实现方式**:
- 使用`winreg`模块操作Windows注册表
- 首次运行自动添加到启动项
- 支持通过API管理启动项状态

- **操作系统**: Windows 10/11 (64位)
- **Python**: 3.8 或更高版本
- **内存**: 建议 4GB 以上
- **磁盘空间**: 至少 500MB

#### 2.4.4 常见运行问题

**问题1: 模块导入错误**

**症状**: `ModuleNotFoundError: No module named 'xxx'`

**解决**:
1. 确保已激活虚拟环境
2. 检查是否安装了所有依赖：`pip install -r requirements.txt`
3. 检查 `PYTHONPATH` 是否正确设置

**问题2: 端口被占用**

**症状**: `OSError: [WinError 10048] 通常每个套接字地址(协议/网络地址/端口)只允许使用一次`

**解决**:
```bash
# 检查端口占用
netstat -ano | findstr :8099

# 结束占用端口的进程
taskkill /PID <进程ID> /F

# 或修改 config.py 中的 PORT 配置
```

**问题3: 浏览器驱动未找到**

**症状**: `Playwright 浏览器驱动未安装`

**解决**:
```bash
# 安装浏览器驱动
venv\Scripts\python.exe -m playwright install chromium
```

**问题4: 系统托盘图标不显示**

**症状**: 托盘图标未出现

**解决**:
1. 检查是否安装了 `pystray` 和 `Pillow`
2. 检查 `config.py` 中 `TRAY_ENABLED` 是否为 `True`
3. 查看控制台是否有错误信息

### 3.2 添加新工具

#### 步骤1: 创建工具类

在 `src/tools/` 目录下创建新文件，例如 `my_tool.py`:

```python
from tools.base import BaseTool

class MyTool(BaseTool):
    def __init__(self):
        super().__init__(
            name="my_tool",           # 工具唯一标识符（英文）
            display_name="我的工具",  # 显示名称（中文）
            description="工具描述"
        )
        # 初始化工具自己的变量
        self.data = None
    
    def get_info(self):
        """获取工具信息"""
        return {
            "name": self.name,
            "display_name": self.display_name,
            "description": self.description,
            "icon": "🔧"  # 图标（emoji或路径）
        }
    
    def initialize(self, **kwargs):
        """初始化工具"""
        # 初始化逻辑
        self.data = {}
        return True
    
    def cleanup(self):
        """清理工具资源"""
        self.data = None
```

#### 步骤2: 注册工具

在 `src/app.py` 的 `init_tools()` 函数中注册：

```python
def init_tools(browser_pool: BrowserPool) -> ToolManager:
    tool_manager = ToolManager()
    
    # 注册爬虫工具
    spider_tool = SpiderTool()
    tool_manager.register_tool(spider_tool)
    
    # 注册新工具
    from tools.my_tool import MyTool
    my_tool = MyTool()
    tool_manager.register_tool(my_tool)
    
    # 初始化所有工具
    init_results = tool_manager.initialize_all(browser_pool=browser_pool)
    
    return tool_manager
```

#### 5.2.1 文件结构

```python
# -*- mode: python ; coding: utf-8 -*-
"""
PyInstaller打包配置文件
"""

# 1. 路径配置
project_root = Path(SPECPATH)  # spec文件所在目录
src_dir = project_root / 'src'  # 源代码目录

# 2. Analysis - 分析阶段
a = Analysis(...)

# 3. PYZ - Python字节码打包
pyz = PYZ(a.pure)

# 4. EXE - 可执行文件配置
exe = EXE(...)

# 5. COLLECT - 收集所有文件
coll = COLLECT(...)
```

#### 5.2.2 Analysis 配置详解

```python
a = Analysis(
    # scripts: 主程序入口文件列表
    [str(src_dir / 'main.py')],
    
    # pathex: Python模块搜索路径
    pathex=[str(src_dir)],
    
    # binaries: 二进制文件列表（如DLL）
    binaries=[],
    
    # datas: 数据文件列表（模板、静态资源等）
    datas=[
        (str(src_dir / 'web' / 'templates'), 'web/templates'),
        (str(src_dir / 'static'), 'static'),
    ],
    # 格式: (源路径, 目标相对路径)
    
    # hiddenimports: 隐藏导入的模块
    # PyInstaller可能无法自动检测到的模块
    hiddenimports=[
        'pystray',              # 系统托盘库
        'PIL',                  # 图像处理库
        'pystray._win32',       # Windows平台特定模块
        'flask',                # Flask框架
        'playwright',           # 浏览器自动化
        # ... 其他模块
    ],
    
    # hookspath: 自定义hook路径
    hookspath=[],
    
    # runtime_hooks: 运行时hook文件
    runtime_hooks=[],
    
    # excludes: 排除的模块（减小体积）
    excludes=[],
    
    # noarchive: 是否不打包为归档文件
    noarchive=False,
    
    # optimize: Python优化级别（0=不优化）
    optimize=0,
)
```

**关键配置说明**:

1. **datas**: 指定需要打包的数据文件
   - 格式：`(源路径, 目标相对路径)`
   - 打包后，文件会复制到exe同目录下的目标路径

2. **hiddenimports**: 显式指定需要导入的模块
   - 用于解决PyInstaller无法自动检测的模块
   - 特别是平台特定的模块（如`pystray._win32`）

3. **pathex**: 添加模块搜索路径
   - 确保能找到项目中的模块

#### 5.2.3 EXE 配置详解

```python
exe = EXE(
    # pyz: Python字节码归档
    pyz,
    
    # a.scripts: 脚本文件
    a.scripts,
    
    # exclude_binaries: 是否排除二进制文件
    # True表示二进制文件单独收集（用于onedir模式）
    exclude_binaries=True,
    
    # name: 可执行文件名称
    name='main',
    
    # debug: 是否包含调试信息
    debug=False,
    
    # console: 是否显示控制台窗口
    # True=显示控制台（方便调试）
    # False=不显示控制台（窗口应用）
    console=True,
    
    # disable_windowed_traceback: 是否禁用窗口化错误追踪
    disable_windowed_traceback=False,
    
    # upx: 是否使用UPX压缩（减小体积）
    upx=True,
    
    # strip: 是否去除符号信息（减小体积）
    strip=False,
)
```

**关键配置说明**:

1. **console**: 
   - `True`: 显示控制台窗口，可以看到所有print输出，方便调试
   - `False`: 不显示控制台，适合最终发布版本

2. **exclude_binaries=True**: 
   - 用于onedir模式（目录模式）
   - 二进制文件会单独收集，不打包进exe

3. **upx**: 
   - 使用UPX压缩可减小exe体积
   - 需要安装UPX工具

#### 5.2.4 COLLECT 配置详解

```python
coll = COLLECT(
    # exe: 可执行文件
    exe,

    a.binaries,

    a.datas,

    name='main',
    
    # strip: 是否去除符号信息
    strip=False,
    
    # upx: 是否使用UPX压缩
    upx=True,
)
```

**说明**: COLLECT用于onedir模式，将所有文件收集到一个目录中。

### 5.3 打包模式选择

#### 5.3.1 onedir模式（目录模式，当前使用）

**特点**:
- 生成一个目录，包含exe和所有依赖文件
- 启动速度较快
- 文件较大但易于调试

**适用场景**: 开发测试、需要频繁更新的场景

#### 5.3.2 onefile模式（单文件模式）

如果要改为onefile模式，修改`main.spec`:

```python
exe = EXE(
    pyz,
    a.scripts,
    a.binaries,      # 不排除二进制文件
    a.datas,         # 包含数据文件
    exclude_binaries=False,  # 改为False
    name='main',
    console=True,
    # ... 其他配置
)
# 删除COLLECT部分
```

**特点**:
- 生成单个exe文件
- 启动时需要解压，速度较慢
- 文件体积较大

**适用场景**: 最终发布版本

### 5.4 打包注意事项

1. **必须在虚拟环境中打包**
   - 确保依赖版本一致
   - 避免打包系统Python的库

2. **浏览器驱动处理**
   - Playwright浏览器驱动需要单独处理
   - 打包后需要确保浏览器驱动在正确位置

3. **路径问题**
   - 打包后路径会变化
   - 代码中使用`sys.frozen`判断是否为打包环境
   - 使用绝对路径或相对于exe的路径

4. **测试打包结果**
   - 在干净的Windows系统上测试
   - 确保所有功能正常

### 7.2 注册表操作详解

#### 7.2.1 使用的Windows API

```python
import winreg

# 打开注册表键
key = winreg.OpenKey(
    winreg.HKEY_CURRENT_USER,  # 主键
    STARTUP_REG_KEY,            # 子键路径
    0,                          # 保留参数
    winreg.KEY_WRITE            # 访问权限
)

# 写入值
winreg.SetValueEx(
    key,                    # 注册表键
    STARTUP_APP_NAME,       # 值名称
    0,                      # 保留参数
    winreg.REG_SZ,          # 数据类型（字符串）
    exe_path_quoted         # 值内容（带引号的路径）
)

# 读取值
value, _ = winreg.QueryValueEx(key, STARTUP_APP_NAME)

# 删除值
winreg.DeleteValue(key, STARTUP_APP_NAME)

# 关闭键
winreg.CloseKey(key)
```

#### 7.2.2 路径处理


**原因**: Windows注册表中的启动项路径如果包含空格，需要用引号包裹。

### 7.3 开机自启动流程

```

4. 写入注册表: HKEY_CURRENT_USER\...\Run\JNSpider = "exe路径"
   ↓

```
