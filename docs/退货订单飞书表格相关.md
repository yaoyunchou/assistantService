## 数据来源：JS 脚本

**脚本路径**：`src/spider/pinduoduo/scripts/pdd-after-sale-return-logistics.js`

**目标页面**：`https://mms.pinduoduo.com/erp/after-sale/manage`

**脚本返回 results 数组，每条结构**：

```js
{
  orderNo:      "180xxxxxxxxxxxxxxxxx",  // 平台订单号（18-20位）
  carrier:      "韵达",                  // 快递公司
  trackNo:      "465332904015842",       // 快递单号
  latestStatus: "【代收点】...",          // 最新物流状态
  allStatuses:  ["2026-05-15 12:07:43 ...", "..."],  // 全部节点
  fullText:     "韵达465332904015842...", // Popover 原文
  collectedAt:  1747471234567            // 采集时间戳(ms)，前端采集后注入
}
```

## 字段映射关系

| JS 字段 | 飞书字段名 | 飞书字段 ID | 说明 |
|---------|-----------|------------|------|
| `orderNo` | 订单号 | `flda8A2YvW` | 主键，用于 upsert 去重 |
| `carrier` | 快递公司 | `fldV7RWALE` | |
| `trackNo` | 快递单号 | `fldEmnsYxl` | |
| `latestStatus` | 最新物流状态 | `fldW6H5WZS` | |
| `allStatuses` (join `\n`) | 物流节点 | `fldmhWeejh` | 每行一条节点，截断 49000 字符 |
| `collectedAt` (ms) | 采集时间 | `fld3jWhmVq` | 前端注入 `Date.now()`，datetime 类型需传 Unix 毫秒 |

> **注**：原脚本返回的 `fullText`（物流原文）暂不写入飞书（避免超字符限制）；如需可自行添加 text 列映射。

## 同步逻辑

```
ERP 售后页（浏览器）
  → 执行 pdd-after-sale-return-logistics.js
  → 返回 results[]（Python 侧注入 collectedAt=当前时间戳ms）
  → 前端展示数据表格
  → 自动调用 feishutable.sync_after_sale_logistics_to_feishu()
      - 读取表中所有记录，按「订单号」建索引
      - 已存在 且「是否处理」= true  → 跳过（保留人工标记）
      - 已存在 且「是否处理」= false → 更新物流字段 + 采集时间
      - 不存在 → 新建（「是否处理」默认 false）
      - 批量操作，每批 20 条
```

### API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/pinduoduo/erp-after-sale/collect` | 采集 + 自动同步飞书（主入口，需浏览器） |
| POST | `/api/pinduoduo/erp-after-sale/sync-to-feishu` | 接收 results 数组同步到飞书（无需浏览器，可单独调用） |
| POST | `/api/pinduoduo/erp-after-sale/sync` | 一键采集 + 同步（备用，与 collect 等效） |
