# 重构总结 - 2026年1月23日

## 重构概述

今天完成了一次重要的架构重构和性能优化，主要聚焦于浏览器池管理和代码简化。

## 主要改进

### 1. 浏览器池智能复用机制 🚀

**改进前：**
- 每次调用创建新浏览器，使用完立即关闭
- 频繁创建/销毁浪费大量时间和资源
- 每次调用耗时 3-5秒

**改进后：**
- 浏览器使用完后标记为空闲，可被复用
- 空闲超过10分钟自动清理
- 首次调用 3-5秒，后续调用 < 0.1秒
- **性能提升：30-50倍**

**实现细节：**
- 使用 `BrowserInstance` 数据类管理浏览器状态
- 实例池 + 空闲/忙碌状态标记
- **线程绑定**：每个线程只复用自己创建的浏览器实例（避免 Playwright 跨线程问题）
- 后台清理线程自动回收超时实例
- 线程安全设计，支持并发访问

### 2. 浏览器操作超时控制 ⏱️

**功能：**
- 所有浏览器操作支持超时控制
- 默认超时：60秒（1分钟）
- 可自定义每次调用的超时时间

**优点：**
- 超时后自动释放资源
- 不会阻塞其他请求
- 详细的日志记录
- 清晰的异常处理

**使用示例：**
```python
# 默认60秒超时
with browser_pool.get_page() as page:
    page.goto('https://example.com')

# 自定义超时
with browser_pool.get_page(timeout=30) as page:
    page.goto('https://example.com')
```

### 3. 代码简化和去除过度抽象 🎯

**删除的冗余代码：**

1. **删除 `_ensure_browser_pool_initialized()` 函数**
   - 路由层不应该负责创建浏览器池
   - 浏览器池在应用启动时初始化

2. **简化拼多多路由**
   - 去除工具层的回调包装
   - 直接使用 `BrowserPool` 和 `PinduoduoClient`
   - 代码行数减少 50%

**改进前（过度抽象）：**
```python
# 1. 获取工具
tool_manager = get_tool_manager()
tool = tool_manager.get_tool('pinduoduo')

# 2. 定义回调
def login_callback(client):
    return client.show_login_qrcode()

# 3. 通过工具执行回调
qrcode_data = tool.execute_with_client(login_callback)
```

**改进后（直接清晰）：**
```python
# 直接使用浏览器池和客户端
from spider.pinduoduo.client import PinduoduoClient

with _browser_pool_ref.get_page(timeout=60) as page:
    client = PinduoduoClient(page=page)
    qrcode_data = client.show_login_qrcode()
```

## 职责分离

### 改进后的架构

| 层级 | 职责 | 关注点 |
|------|------|--------|
| **BrowserPool** | - 创建和管理浏览器实例<br>- 智能复用和清理<br>- 超时控制<br>- 线程安全 | 资源管理 |
| **Client** | - 业务逻辑实现<br>- 页面操作<br>- 数据提取 | 业务功能 |
| **路由层** | - 参数验证<br>- 调用客户端<br>- 返回结果 | HTTP接口 |

**关键原则：**
- 单一职责：每个模块只做一件事
- 关注点分离：各层互不干扰
- 依赖注入：浏览器池通过参数传递

## 重要修复：Playwright 跨线程问题

### 问题
- 浏览器复用时出现 `greenlet.error: cannot switch to a different thread`
- Playwright 同步 API 不支持跨线程使用同一个浏览器实例

### 解决方案
- **线程绑定**：只复用当前线程创建的浏览器实例
- 检查 `instance.thread_id == current_thread_id`
- 不同线程会创建独立的浏览器实例

### 影响
- 同一线程内仍可复用（性能优化保留）
- 不同线程独立管理（线程隔离）
- 完全解决 Playwright 跨线程问题
