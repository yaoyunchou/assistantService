# 浏览器池调用规范文档

## 概述

本文档说明如何使用 `BrowserPool` 进行批量爬虫任务，包括如何循环派发任务给浏览器、处理异常、超时控制等最佳实践。

## 核心概念

### BrowserPool 特性

- **智能复用**：浏览器使用完后标记为空闲状态，可被其他请求复用
- **自动清理**：空闲超过10分钟的浏览器自动关闭释放资源
- **动态扩展**：根据等待队列长度自动扩展浏览器实例数（最多5个）
- **线程安全**：支持并发访问，所有浏览器共享同一个持久化用户数据目录
- **超时控制**：所有操作都支持超时控制，默认60秒

### 渐进式扩展策略

浏览器池会根据等待队列长度自动扩展：

| 等待队列长度 | 扩展到的实例数 |
|------------|--------------|
| > 5 个     | 2 个实例     |
| > 20 个    | 3 个实例     |
| > 30 个    | 4 个实例     |
| > 40 个    | 5 个实例     |

## 基础使用

### 1. 初始化浏览器池

```python
from spider.query_manager import BrowserPool

# 创建浏览器池实例
browser_pool = BrowserPool(
    headless=True,          # 是否使用无头模式（默认：True）
    idle_timeout=600,       # 空闲超时时间（秒），默认600秒（10分钟）
    max_instances=5         # 最大浏览器实例数，默认5个
)
```

### 2. 获取页面对象（上下文管理器）

```python
# 使用上下文管理器获取页面
with browser_pool.get_page(timeout=60) as page:
    # 执行爬虫操作
    page.goto('https://example.com')
    content = page.content()
    # ... 其他操作
# 离开 with 块后，浏览器自动标记为空闲，可被其他请求复用
```

### 3. 关闭浏览器池

```python
# 程序结束时，关闭浏览器池释放所有资源
browser_pool.close()
```

## 批量任务处理

### 场景：循环派发任务给浏览器

假设你有一组数据需要爬取，需要循环派发任务给浏览器。

#### 方案一：顺序处理（推荐用于小批量数据）

```python
from spider.query_manager import BrowserPool, BrowserTimeoutError

# 初始化浏览器池
browser_pool = BrowserPool(headless=True, idle_timeout=600, max_instances=5)

# 待处理的数据列表
data_list = [
    {'id': 1, 'url': 'https://example.com/item/1'},
    {'id': 2, 'url': 'https://example.com/item/2'},
    {'id': 3, 'url': 'https://example.com/item/3'},
    # ... 更多数据
]

# 结果列表
results = []

# 顺序处理每个数据项
for item in data_list:
    try:
        # 使用浏览器池获取页面
        with browser_pool.get_page(timeout=60) as page:
            # 访问URL
            page.goto(item['url'])
            
            # 等待页面加载
            page.wait_for_load_state('networkidle')
            
            # 提取数据
            title = page.query_selector('h1').inner_text()
            content = page.query_selector('.content').inner_text()
            
            # 保存结果
            results.append({
                'id': item['id'],
                'url': item['url'],
                'title': title,
                'content': content,
                'status': 'success'
            })
            
            print(f"✓ 成功处理: {item['id']}")
            
    except BrowserTimeoutError as e:
        # 超时处理
        print(f"✗ 超时: {item['id']} - {e}")
        results.append({
            'id': item['id'],
            'url': item['url'],
            'status': 'timeout',
            'error': str(e)
        })
        
    except Exception as e:
        # 其他异常处理
        print(f"✗ 错误: {item['id']} - {e}")
        results.append({
            'id': item['id'],
            'url': item['url'],
            'status': 'error',
            'error': str(e)
        })

# 关闭浏览器池
browser_pool.close()

# 输出结果统计
success_count = sum(1 for r in results if r['status'] == 'success')
print(f"\n处理完成: 成功 {success_count}/{len(data_list)}")
```

#### 方案二：并发处理（推荐用于大批量数据）

使用 `concurrent.futures` 实现并发处理，充分利用浏览器池的多个实例：

```python
from spider.query_manager import BrowserPool, BrowserTimeoutError
from concurrent.futures import ThreadPoolExecutor, as_completed
import time

# 初始化浏览器池
browser_pool = BrowserPool(headless=True, idle_timeout=600, max_instances=5)

# 待处理的数据列表
data_list = [
    {'id': 1, 'url': 'https://example.com/item/1'},
    {'id': 2, 'url': 'https://example.com/item/2'},
    # ... 更多数据
]

# 处理单个数据项的函数
def process_item(item):
    """处理单个数据项"""
    try:
        # 使用浏览器池获取页面
        with browser_pool.get_page(timeout=60) as page:
            # 访问URL
            page.goto(item['url'])
            
            # 等待页面加载
            page.wait_for_load_state('networkidle')
            
            # 提取数据
            title = page.query_selector('h1').inner_text()
            content = page.query_selector('.content').inner_text()
            
            return {
                'id': item['id'],
                'url': item['url'],
                'title': title,
                'content': content,
                'status': 'success'
            }
            
    except BrowserTimeoutError as e:
        # 超时处理
        return {
            'id': item['id'],
            'url': item['url'],
            'status': 'timeout',
            'error': str(e)
        }
        
    except Exception as e:
        # 其他异常处理
        return {
            'id': item['id'],
            'url': item['url'],
            'status': 'error',
            'error': str(e)
        }

# 使用线程池并发处理
results = []
max_workers = min(5, len(data_list))  # 最多5个并发（对应最大实例数）

with ThreadPoolExecutor(max_workers=max_workers) as executor:
    # 提交所有任务
    future_to_item = {
        executor.submit(process_item, item): item 
        for item in data_list
    }
    
    # 收集结果
    for future in as_completed(future_to_item):
        item = future_to_item[future]
        try:
            result = future.result()
            results.append(result)
            
            if result['status'] == 'success':
                print(f"✓ 成功处理: {item['id']}")
            else:
                print(f"✗ 失败: {item['id']} - {result.get('error', 'unknown')}")
                
        except Exception as e:
            print(f"✗ 异常: {item['id']} - {e}")
            results.append({
                'id': item['id'],
                'url': item['url'],
                'status': 'error',
                'error': str(e)
            })

# 关闭浏览器池
browser_pool.close()

# 输出结果统计
success_count = sum(1 for r in results if r['status'] == 'success')
print(f"\n处理完成: 成功 {success_count}/{len(data_list)}")
```

## 完整示例

### 示例：批量爬取商品信息

```python
"""
批量爬取商品信息的完整示例
"""
from spider.query_manager import BrowserPool, BrowserTimeoutError
from concurrent.futures import ThreadPoolExecutor, as_completed
import json
import time
from typing import List, Dict, Optional

class ProductCrawler:
    """商品爬虫类"""
    
    def __init__(self, headless: bool = True, max_instances: int = 5):
        """
        初始化爬虫
        
        Args:
            headless: 是否使用无头模式
            max_instances: 最大浏览器实例数
        """
        self.browser_pool = BrowserPool(
            headless=headless,
            idle_timeout=600,
            max_instances=max_instances
        )
        self.results: List[Dict] = []
    
    def crawl_product(self, product_id: str, url: str, timeout: float = 60.0) -> Dict:
        """
        爬取单个商品信息
        
        Args:
            product_id: 商品ID
            url: 商品URL
            timeout: 超时时间（秒）
            
        Returns:
            商品信息字典
        """
        try:
            with self.browser_pool.get_page(timeout=timeout) as page:
                # 访问商品页面
                page.goto(url, wait_until='networkidle')
                
                # 提取商品信息
                title = page.query_selector('h1.product-title')
                title_text = title.inner_text() if title else 'N/A'
                
                price = page.query_selector('.price')
                price_text = price.inner_text() if price else 'N/A'
                
                description = page.query_selector('.description')
                description_text = description.inner_text() if description else 'N/A'
                
                return {
                    'product_id': product_id,
                    'url': url,
                    'title': title_text,
                    'price': price_text,
                    'description': description_text,
                    'status': 'success',
                    'timestamp': time.time()
                }
                
        except BrowserTimeoutError as e:
            return {
                'product_id': product_id,
                'url': url,
                'status': 'timeout',
                'error': str(e),
                'timestamp': time.time()
            }
            
        except Exception as e:
            return {
                'product_id': product_id,
                'url': url,
                'status': 'error',
                'error': str(e),
                'timestamp': time.time()
            }
    
    def batch_crawl(self, product_list: List[Dict], max_workers: int = 5, timeout: float = 60.0):
        """
        批量爬取商品信息
        
        Args:
            product_list: 商品列表，每个元素包含 {'id': str, 'url': str}
            max_workers: 最大并发数（建议不超过 max_instances）
            timeout: 每个任务的超时时间（秒）
        """
        print(f"开始批量爬取，共 {len(product_list)} 个商品")
        print(f"并发数: {max_workers}, 超时时间: {timeout} 秒")
        
        start_time = time.time()
        results = []
        
        # 使用线程池并发处理
        with ThreadPoolExecutor(max_workers=max_workers) as executor:
            # 提交所有任务
            future_to_product = {
                executor.submit(self.crawl_product, item['id'], item['url'], timeout): item
                for item in product_list
            }
            
            # 收集结果
            completed = 0
            for future in as_completed(future_to_product):
                product = future_to_product[future]
                completed += 1
                
                try:
                    result = future.result()
                    results.append(result)
                    
                    # 显示进度
                    status_icon = '✓' if result['status'] == 'success' else '✗'
                    print(f"[{completed}/{len(product_list)}] {status_icon} {product['id']}: {result['status']}")
                    
                except Exception as e:
                    print(f"[{completed}/{len(product_list)}] ✗ {product['id']}: 异常 - {e}")
                    results.append({
                        'product_id': product['id'],
                        'url': product['url'],
                        'status': 'error',
                        'error': str(e),
                        'timestamp': time.time()
                    })
        
        elapsed_time = time.time() - start_time
        self.results = results
        
        # 输出统计信息
        success_count = sum(1 for r in results if r['status'] == 'success')
        timeout_count = sum(1 for r in results if r['status'] == 'timeout')
        error_count = sum(1 for r in results if r['status'] == 'error')
        
        print(f"\n{'='*50}")
        print(f"爬取完成！")
        print(f"总耗时: {elapsed_time:.2f} 秒")
        print(f"成功: {success_count} 个")
        print(f"超时: {timeout_count} 个")
        print(f"错误: {error_count} 个")
        print(f"成功率: {success_count/len(product_list)*100:.1f}%")
        print(f"{'='*50}")
    
    def save_results(self, filepath: str):
        """保存结果到JSON文件"""
        with open(filepath, 'w', encoding='utf-8') as f:
            json.dump(self.results, f, ensure_ascii=False, indent=2)
        print(f"结果已保存到: {filepath}")
    
    def close(self):
        """关闭浏览器池"""
        self.browser_pool.close()
        print("浏览器池已关闭")


# 使用示例
if __name__ == '__main__':
    # 准备商品列表
    products = [
        {'id': 'P001', 'url': 'https://example.com/product/1'},
        {'id': 'P002', 'url': 'https://example.com/product/2'},
        {'id': 'P003', 'url': 'https://example.com/product/3'},
        # ... 更多商品
    ]
    
    # 创建爬虫实例
    crawler = ProductCrawler(headless=True, max_instances=5)
    
    try:
        # 批量爬取
        crawler.batch_crawl(products, max_workers=5, timeout=60)
        
        # 保存结果
        crawler.save_results('products_results.json')
        
    finally:
        # 关闭浏览器池
        crawler.close()
```

## 最佳实践

### 1. 超时时间设置

根据任务复杂度设置合适的超时时间：

```python
# 快速查询操作：15-30秒
with browser_pool.get_page(timeout=30) as page:
    page.goto('https://example.com')
    # 简单操作

# 页面加载操作：30-60秒
with browser_pool.get_page(timeout=60) as page:
    page.goto('https://example.com')
    page.wait_for_load_state('networkidle')
    # 等待页面完全加载

# 复杂自动化操作：60-120秒
with browser_pool.get_page(timeout=120) as page:
    page.goto('https://example.com')
    # 复杂的交互操作
```

### 2. 异常处理

始终使用 try-except 处理异常：

```python
from spider.query_manager import BrowserTimeoutError

try:
    with browser_pool.get_page(timeout=60) as page:
        # 执行操作
        pass
except BrowserTimeoutError:
    # 超时处理
    print("操作超时")
except Exception as e:
    # 其他异常处理
    print(f"操作失败: {e}")
```

### 3. 并发数设置

并发数建议不超过浏览器池的最大实例数：

```python
# 推荐：并发数 = 最大实例数
max_workers = browser_pool.max_instances  # 默认5

# 如果数据量小，可以减少并发数
max_workers = min(3, len(data_list))
```

### 4. 资源清理

程序结束时记得关闭浏览器池：

```python
try:
    # 执行爬虫任务
    pass
finally:
    # 确保关闭浏览器池
    browser_pool.close()
```

### 5. 进度监控

对于大批量任务，建议添加进度监控：

```python
total = len(data_list)
completed = 0

for item in data_list:
    # 处理任务
    completed += 1
    print(f"进度: {completed}/{total} ({completed/total*100:.1f}%)")
```

### 6. 结果保存

定期保存结果，避免程序异常导致数据丢失：

```python
results = []

# 每处理100个保存一次
for i, item in enumerate(data_list):
    result = process_item(item)
    results.append(result)
    
    if (i + 1) % 100 == 0:
        save_results(results)  # 定期保存
```

## 监控和调试

### 获取浏览器池状态

```python
# 获取浏览器池状态信息

print(f"总实例数: {status['total']}")

# 查看每个实例的详细信息
for instance in status['instances']:
    print(f"实例 {instance['index']}: "
          f"忙碌={instance['is_busy']}, "

```

### 性能优化建议

1. **合理设置并发数**：不要超过 `max_instances`，避免创建过多等待任务
2. **调整超时时间**：根据实际网络环境和页面复杂度调整
3. **使用无头模式**：生产环境建议使用 `headless=True` 节省资源
4. **批量处理**：对于大量数据，使用并发处理提升效率
5. **错误重试**：对于失败的任务，可以实现重试机制

## 常见问题

### Q1: 如何知道浏览器池是否正常工作？

A: 可以通过 `get_pool_status()` 方法查看状态，或者观察日志输出。

### Q2: 为什么我的任务执行很慢？

A: 可能的原因：
- 并发数设置过小
- 超时时间设置过长
- 网络环境较差
- 页面加载较慢

建议：增加并发数、调整超时时间、检查网络环境。

### Q3: 如何处理超时任务？

A: 捕获 `BrowserTimeoutError` 异常，记录失败信息，可以选择重试或跳过。

### Q4: 浏览器池会自动清理吗？

A: 是的，空闲超过10分钟（默认）的浏览器会自动关闭。可以通过 `idle_timeout` 参数调整。

### Q5: 可以同时运行多个浏览器池吗？

A: 可以，但不推荐。每个浏览器池都会创建独立的浏览器实例，会占用更多资源。建议使用一个浏览器池，通过并发处理提升效率。

## 总结

使用 `BrowserPool` 进行批量爬虫任务的核心要点：

1. ✅ 使用上下文管理器 `with browser_pool.get_page()` 获取页面
2. ✅ 合理设置超时时间，避免任务卡死
3. ✅ 使用并发处理提升效率（推荐 `ThreadPoolExecutor`）
4. ✅ 完善的异常处理，确保程序稳定运行
5. ✅ 程序结束时关闭浏览器池，释放资源
6. ✅ 定期保存结果，避免数据丢失

遵循以上规范，可以高效、稳定地完成批量爬虫任务。
