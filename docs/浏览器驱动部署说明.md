# 浏览器驱动部署说明

## 问题描述

打包后的 exe 运行时提示：
```
playwright._impl._errors.Error: BrowserType.launch: Executable doesn't exist at ...
```

## 原因

Playwright 浏览器驱动需要单独部署，不会自动打包到 exe 中。

## 解决方案

### 方法1：手动复制浏览器驱动（推荐）

#### 步骤1：安装浏览器驱动

在开发环境中安装 Playwright 浏览器驱动：

```bash
# 激活虚拟环境
venv\Scripts\activate.bat

# 安装浏览器驱动
venv\Scripts\python.exe -m playwright install chromium
```

#### 步骤2：找到浏览器驱动位置

浏览器驱动通常安装在：
```
%USERPROFILE%\AppData\Local\ms-playwright\chromium-XXXX\
```

或者项目目录下（如果设置了环境变量）：
```
项目目录\playwright_drivers\chromium-XXXX\
```

#### 步骤3：复制到打包目录

将浏览器驱动复制到打包后的 exe 同目录：

```
dist/main/
├── main.exe
├── playwright_drivers/          # 需要手动创建并复制
│   └── chromium-XXXX/
│       └── chrome-win/
│           └── chrome.exe
└── ... (其他文件)
```

**具体操作**：

1. 找到浏览器驱动目录（通常在 `%USERPROFILE%\AppData\Local\ms-playwright\chromium-XXXX\`）
2. 在 `dist/main/` 目录下创建 `playwright_drivers` 目录
3. 将整个 `chromium-XXXX` 目录复制到 `dist/main/playwright_drivers/` 下

### 方法2：使用系统安装的浏览器驱动

如果系统已安装 Playwright 浏览器驱动，程序会自动查找并使用。

安装位置：`%USERPROFILE%\AppData\Local\ms-playwright\chromium-XXXX\`

### 方法3：创建部署脚本（自动化）

创建 `deploy_browser.bat` 脚本：

```batch
@echo off
echo 正在复制浏览器驱动...

set PLAYWRIGHT_DIR=%USERPROFILE%\AppData\Local\ms-playwright
set TARGET_DIR=dist\main\playwright_drivers

if not exist "%TARGET_DIR%" mkdir "%TARGET_DIR%"

for /d %%d in ("%PLAYWRIGHT_DIR%\chromium-*") do (
    echo 复制 %%d 到 %TARGET_DIR%...
    xcopy /E /I /Y "%%d" "%TARGET_DIR%\%%~nxd"
    goto :found
)

:found
echo 浏览器驱动复制完成！
pause
```

运行脚本：
```bash
deploy_browser.bat
```

## 验证

部署后，运行 exe 时应该看到：

```
[BrowserPath] ✓ 找到浏览器驱动: D:\path\to\dist\main\playwright_drivers\chromium-XXXX\chrome-win\chrome.exe
[BrowserPath] ✓ 设置 PLAYWRIGHT_BROWSERS_PATH: D:\path\to\dist\main\playwright_drivers
```

## 注意事项

1. **目录结构必须正确**：
   ```
   dist/main/playwright_drivers/chromium-XXXX/chrome-win/chrome.exe
   ```

2. **完整复制**：必须复制整个 `chromium-XXXX` 目录，不能只复制 `chrome.exe`

3. **路径检查**：如果仍然报错，检查控制台输出的路径信息，确认路径是否正确

4. **权限问题**：确保 exe 有权限访问浏览器驱动目录
