# 开机自启动功能测试指南

## 功能说明

蕉内工具箱支持开机自动启动功能，应用会在系统启动时自动运行。

## 配置位置

- **注册表位置**: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
- **注册表键名**: `JNTools`
- **注册表值**: 应用exe文件的完整路径（带引号）

## 自动添加机制

应用首次启动时会自动检查并添加到开机自启动：
- 如果未添加，自动添加到注册表
- 如果已存在，不重复添加
- 启动日志会显示："检测到未设置开机自启动，正在自动添加..." 或 "开机自启动已启用"

## 测试方法

### 方法1：查看启动日志

1. 运行应用
2. 查看日志文件 `logs/app_YYYY-MM-DD.log`
3. 查找以下日志信息：
   - `[Main] 检测到未设置开机自启动，正在自动添加...`
   - `[Main] 开机自启动已启用`

### 方法2：使用注册表编辑器

1. 按 `Win + R` 打开运行对话框
2. 输入 `regedit` 并回车
3. 导航到：`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
4. 查找键名 `JNTools`
5. 检查值是否为应用exe的完整路径（带引号）

### 方法3：使用API接口测试

#### 查询自启动状态
```bash
# 使用 curl
curl http://127.0.0.1:8889/startup

# 使用浏览器
http://127.0.0.1:8889/startup
```

**响应示例**:
```json
{
  "success": true,
  "startup_enabled": true,
  "exe_path": "D:\\work\\work\\work\\2026\\python\\kuaidi\\dist\\JNTools\\JNTools.exe"
}
```

#### 启用自启动
```bash
# 使用 curl
curl -X POST http://127.0.0.1:8889/startup

# 使用浏览器（需要安装插件支持POST请求）
```

**响应示例**:
```json
{
  "success": true,
  "message": "已启用开机自启动",
  "startup_enabled": true
}
```

#### 禁用自启动
```bash
# 使用 curl
curl -X DELETE http://127.0.0.1:8889/startup
```

**响应示例**:
```json
{
  "success": true,
  "message": "已禁用开机自启动",
  "startup_enabled": false
}
```

### 方法4：实际重启测试

1. 确保应用已添加到开机自启动（使用上述方法验证）
2. 重启电脑
3. 开机后检查：
   - 系统托盘是否出现应用图标
   - 任务管理器是否显示 `JNTools.exe` 进程
   - 应用是否自动启动

## 常见问题

### Q1: 开机自启动不生效

**可能原因**:
- 注册表写入失败（权限不足）
- exe路径错误
- 杀毒软件拦截

**解决方法**:
1. 检查注册表项是否存在
2. 检查exe路径是否正确
3. 检查杀毒软件是否拦截
4. 查看日志文件中的错误信息

### Q2: 如何手动禁用自启动

**方法1**: 使用API接口
```bash
curl -X DELETE http://127.0.0.1:8889/startup
```

**方法2**: 使用注册表编辑器
1. 打开注册表编辑器
2. 导航到 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
3. 删除 `JNTools` 键

**方法3**: 使用任务管理器
1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 切换到"启动"标签
3. 找到"蕉内工具箱"或"JNTools"
4. 右键选择"禁用"

### Q3: 开发环境自启动问题

**说明**:
- 开发环境会使用Python脚本路径（`main.py`）
- 需要确保Python环境正确配置
- 建议只在打包后的exe中使用自启动功能

## 技术实现

### 核心函数

- `is_startup_enabled()`: 检查是否已添加到开机启动
- `add_to_startup()`: 添加到开机启动
- `remove_from_startup()`: 从开机启动中移除
- `get_exe_path()`: 获取exe文件路径

### 代码位置

- **实现文件**: `src/utils/startup.py`
- **自动添加逻辑**: `src/main.py` 的 `main()` 函数
- **API接口**: `src/api/routes/health.py` 的 `/startup` 路由

## 注意事项

1. **权限要求**: 修改注册表需要用户权限，通常不需要管理员权限（HKEY_CURRENT_USER）
2. **路径处理**: 路径会自动用引号包裹，以处理路径中的空格
3. **开发环境**: 开发环境使用 `main.py` 路径，打包后使用 `JNTools.exe` 路径
4. **杀毒软件**: 某些杀毒软件可能会拦截注册表修改，需要添加白名单
